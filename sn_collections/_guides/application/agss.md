AGSkySight is an application that includes a graphical user interface for processing imagery from Unmanned Aerial Vehicles (UAVs). It uses OpenDroneMap ([https://opendronemap.org/](https://opendronemap.org/)) for stitching. It is currently available on the Atlas cluster via Open OnDemand. With AGSkySight, users can stitch raw UAV imagery, create shapefiles, and run analysis. This training guide is intended for users to get started using AGSkySight and become familiar with its functionality.

## Launching AGSS in Open OnDemand

1. Sign in to Atlas Open OnDemand at [https://atlas-ood.hpc.msstate.edu/](https://atlas-ood.hpc.msstate.edu/). For more information on login procedures for web-based SCINet access, see the [SCINet access user guide]({{ site.baseurl }}/guides/access/web-based-login).
1. In the top navigation menu under "Interactive Apps", click on "AGSkySight".
